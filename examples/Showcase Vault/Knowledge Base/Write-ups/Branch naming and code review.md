## The rules
- Branches: `feature/<what>`, `fix/<what>`, `experiment/<what>`; delete after merge
- One reviewer for normal changes; two for auth or anything that deletes data
- Put the branch on the task (`🌿 feature/<what>`) so it shows on the project hub
