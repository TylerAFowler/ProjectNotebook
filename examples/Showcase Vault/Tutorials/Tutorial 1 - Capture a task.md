# Tutorial 1: Capture a task
*5 minutes · no Editing view needed · ← [[▶ Start here]] · next: [[Tutorial 2 - Finish, cancel or reopen a task]]*

**You'll learn:** how a task gets into the right project, and which parts of it you type vs. which are added for you.

## Do this
1. Open [[2025 Crash Data Load]].
2. Press the **Quick capture** button under the title (or Ctrl+P → `Project Notes: Quick capture`, preset **Alt+Q**).
3. Pick **✅ Task**, then the project (the one you're on is listed first). Answer the prompts; **Enter skips** any optional one:
   - *What needs doing?* → `Send county code list to Marcus`
   - *Repeats?* → skip
   - *Due date?* → a date next week, e.g. `2026-12-01`
   - *Estimated completion?* → `FY2027 Q3`
   - *Priority?* → Normal
   - *Git branch?* → skip
   - *Who's waiting on this?* → `Marcus Bell`
4. Watch for the ✔ message in the corner.

## See this
| Where | What appeared |
| ----- | ------------- |
| The hub's **Open tasks** | Your task, with its due date |
| [[00 Home]] → *Due this week* / *Others waiting on me* | The same task |
| [[Marcus Bell]] → *Waiting on me* | The same task again: one task, shown everywhere it matters |

## What you typed vs. what was added for you
Open [[2025 Crash Data Load - Tasks]] and press **Ctrl+E** to see the raw line:
```
- [ ] Send county code list to Marcus 📅 2026-12-01 🎯 FY2027 Q3 👤 [[Marcus Bell]] ➕ 2026-11-25
```
- You typed **only the words**. Quick capture added 📅 🎯 👤 from your answers.
- ➕ (created date) is added **automatically**. Later, ✅ (done) and ❌ (cancelled) dates are too.
- **You never need to type these symbols.** If you'd like to: Ctrl+P → `Tasks: Create or edit task` gives a form,
  or type `due` / `start` in a task line and pick from the suggestions.

Press **Ctrl+E** again to go back to Reading view.
