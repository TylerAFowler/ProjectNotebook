# Tutorial 4: Weekly review
*5 minutes · ← [[Tutorial 3 - Run a meeting]] · back to [[▶ Start here]]*

**You'll learn:** how a week's work turns into a report you can paste into the division update.

## Do this
1. During the week, log what you worked on in the daily note: **Today** button on Home (preset **Alt+D**), then
   one bullet per thing, starting with the project: `- [[2025 Crash Data Load]] finished county code mapping`.
2. On Friday press **Weekly review** (preset **Alt+W**) → **This week**.

## See this
Open the new report (or the example [[2026-W47 Weekly Report]]):
- **📣 Let people know**: per person, what was finished or fixed for them.
- Per project: ✅ completed, 🔄 in progress with target quarter, issues found/fixed, requirement changes, meetings,
  decisions, commits by branch, and your log bullets.
- Copy what you need into the division report. Nothing has to be typed twice.

## Make it yours
Something about any of this slow or confusing? Press **Log friction** (Knowledge Base page, or preset **Alt+F**).
That's how the vault gets better.
