# Tutorial 2: Finish, cancel or reopen a task
*5 minutes · ← [[Tutorial 1 - Capture a task]] · next: [[Tutorial 3 - Run a meeting]]*

**You'll learn:** the three ways a task can end, and how to undo any of them, all from Reading view.

## The boxes
| Looks like | Means |
| ---------- | ----- |
| ☐ empty | To do |
| ◐ half-filled | In progress |
| ☑ ~~struck through~~ | Done (✅ date added) |
| ☒ grey, ~~faded~~ | Cancelled (❌ date added) |

## Do this
1. Open [[2025 Crash Data Load]] → **Open tasks**. Click the box of the task from Tutorial 1 **once**: it becomes ◐ in progress.
2. Click it **again**: done ☑. It disappears from *Open tasks* and a ✅ date is added for you.
3. **Cancel** a different task: hover it in *Open tasks* and click the **✏️ pencil** → **Status: Cancelled** → Apply.
   (Clicking the box only cycles to do → in progress → done. Cancelling is always the pencil.)
4. **Reopen** one: open [[2025 Crash Data Load - Tasks]], scroll to **📜 History** and click it open. Your done and
   cancelled tasks are there. Click the ✏️ pencil on one → **Status: Todo**.

## See this
- Done and cancelled tasks leave the hub, Home and people's pages, but stay in the Tasks note's **📜 History**.
- [[2026-W48 Weekly Report]] (or a new **Weekly review**) lists what you finished this week.

> [!tip] In Editing view
> Put the cursor on a task and press **Edit task** (preset **Alt+T**) for the same form. Typing `[x]` or `[-]` by hand
> works too, but then no ✅/❌ date is added.
